# 🔮 Lion ox_inventory Discord Logs

A lightweight and fully configurable Discord logging system for **ox_inventory**. Track inventory activities through detailed Discord embeds with customizable webhooks, colors, and appearance.

Designed to be simple to configure, easy to maintain, and suitable for any FiveM server using ox_inventory.

---

## ✨ Features

* **Inventory Logging** – Track item transfers involving evidence, vehicle trunks, gloveboxes, stashes, containers, ground drops, and players
* **Customizable Webhooks** – Configure separate Discord webhooks for different inventory logs
* **Custom Embed Appearance** – Customize colors, usernames, avatars, author information, thumbnails, and footers
* **Individual Event Settings** – Enable or disable specific log events and customize their titles
* **Detailed Information** – Optionally include player identifiers, coordinates, item metadata, and other useful details
* **Reliable Webhook Delivery** – Automatic retries for Discord rate limits and server errors
* **Simple Configuration** – Everything is configured through a single config
* **Optimized** – Server-side only, with no unnecessary loops

---

## 🌀 Dependencies

* [ox_lib](https://github.com/overextended/ox_lib)
* [ox_inventory](https://github.com/overextended/ox_inventory)
